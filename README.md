# mime — go-freedesktop

Pure-Go (`CGO_ENABLED=0`) implementation of the freedesktop.org
[Shared MIME-info Database](https://specifications.freedesktop.org/shared-mime-info-spec/latest/):
resolve a canonical MIME type from a file's name, its content, or both.

Implementation lands via the initial pull request.
